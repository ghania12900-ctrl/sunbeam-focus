# Sunbeam Focus ☀️

An interactive productivity and focus-tracking web application designed to help students and professionals manage deep-work sessions, organize daily tasks, and maintain momentum. 

🌐 **Live Demo:** [View Live on GitHub Pages](https://ghania12900-ctrl.github.io/sunbeam-focus/)

---

## ✨ Features

* **Customizable Focus Timers:** Built with clean asynchronous state management to handle focus and break intervals smoothly.
* **Task Management Module:** Add, track, and check off daily productivity goals in real-time.
* **Responsive & Minimalist UI:** Styled with clean CSS for seamless use across desktop and mobile browsers.
* **Local State Persistence:** Retains user tasks and session states locally for a smooth user experience.
* **Lightweight & Fast:** Built entirely with vanilla web technologies—no heavy frameworks or complex build steps required.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic document structure and accessibility markup.
* **CSS3:** Modern styling, custom variables, and responsive layout design.
* **JavaScript (ES6+):** Client-side interactivity, DOM manipulation, timer logic, and state management.
